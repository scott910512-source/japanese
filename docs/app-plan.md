# 📱 일본어 재학습 앱 기획서 (가칭: "니혼고 루프 / 日本語ループ")

> **작성일:** 2026-07-31
> **작성 배경:** AI와 대화하며 만든 일본어 학습 노트(프롬프트)를 앱에 다시 넣어
> **재학습 → 기록 저장 → 다음 학습 프롬프트 생성**까지 순환시키는 학습 루프 앱

---

# 1. 한 줄 컨셉

> **"AI 학습 노트를 넣으면, 앱이 복습 자료로 바꿔주고, 복습 결과가 다시 다음 학습 프롬프트가 되는 앱"**

기존 단어장 앱과 다른 점:
- 콘텐츠를 앱이 제공하는 게 아니라, **내가 AI와 공부한 기록 자체가 콘텐츠**가 된다.
- 학습 → 노트(프롬프트) → 앱 임포트 → 복습(퀴즈/SRS) → 기록 → **다음 세션용 프롬프트 자동 생성** → 다시 AI 학습
- 즉, **학습 루프(Loop)가 닫혀 있다.**

---

# 2. 핵심 사용자 시나리오 (학습 루프)

```
┌─────────────────────────────────────────────────────┐
│  ① AI와 일본어 회화/문법 학습 (Claude, ChatGPT 등)  │
│         ↓                                           │
│  ② 표준 포맷으로 학습 노트 생성 (오늘의 노트처럼)   │
│         ↓                                           │
│  ③ 앱에 노트 붙여넣기 / 파일 업로드 → 자동 파싱     │
│         ↓                                           │
│  ④ 앱이 자동 생성:                                  │
│     - 단어 플래시카드 덱                            │
│     - 문법 카드                                     │
│     - 한자 카드                                     │
│     - 회화 복습 문장                                │
│         ↓                                           │
│  ⑤ 복습 모드로 재학습 (SRS 간격 반복)               │
│         ↓                                           │
│  ⑥ 결과 저장: 정답률, 취약 항목, 학습 기록          │
│         ↓                                           │
│  ⑦ "다음 학습 프롬프트" 자동 생성                   │
│     (취약 항목 + 다음 추천 문법 + 추천 회화 주제)   │
│         ↓                                           │
│  ①로 복귀 — 생성된 프롬프트를 AI에 붙여넣고 학습    │
└─────────────────────────────────────────────────────┘
```

# 4. 핵심 기능

## 4.1 노트 임포트 (Import)

- **입력 방식**
  - 마크다운 텍스트 붙여넣기 (MVP)
  - `.md` 파일 업로드
  - (추후) 공유하기 → 앱으로 바로 전송
- **파싱 대상 섹션** (표준 프롬프트 템플릿 기준 — `docs/prompt-template.md` 참고)
  - 📌 오늘의 핵심 문법 → 문법 카드
  - 💬 회화 (질문 / 내 문장 / 자연스러운 표현 / 이유) → 회화 카드
  - 📖 단어 표 (일본어 / 읽기 / 뜻) → 단어 플래시카드
  - 🈶 한자 (신자체·음독·훈독·관련 단어·유래) → 한자 카드
  - 🔁 복습 문장 → 문장 퀴즈
  - 📈 학습 기록 (수준 / 다음 추천 문법 / 추천 회화 주제) → 프로필 & 추천 갱신
- **파싱 전략**
  - 1차: 규칙 기반 파서 (표준 템플릿의 헤더·표 구조 파싱) — 오프라인 동작, 무료
  - 2차(선택): 비정형 노트는 Claude API로 구조화 (JSON 스키마 강제 출력)

## 4.2 재학습 (복습 모드)

| 모드 | 설명 | 예시 |
|------|------|------|
| 🃏 플래시카드 (SRS) | 단어/한자 앞뒤 카드, 간격 반복 | 앞: 駅 → 뒤: えき / 역 |
| ✏️ 빈칸 채우기 | 문법 패턴 빈칸 퀴즈 | 駅までどうやって（　　）いいですか → 行けば |
| 🗣️ 회화 롤플레이 | 상황 제시 → 내 답 입력 → "자연스러운 표현"과 비교 | "카페에서 주문해 보세요" |
| 🈶 한자 퀴즈 | 읽기 맞히기 / 한국 한자음 연결 / 관련 단어 | 駅 → エキ, 驛(역) |
| 🎯 자연스러움 퀴즈 | 교과서 표현 vs 실제 회화 표현 고르기 | 行けます vs 行けますよ |

- **SRS 알고리즘:** MVP는 Leitner 5단계 박스 (오답 → 1단계, 정답 → 다음 단계, 단계별 복습 간격 1/2/4/7/15일). 추후 SM-2 검토.

## 4.3 학습 기록 & 통계

- 세션별 기록: 날짜, 주제, 새 문법/단어 수, 복습 정답률
- 누적 대시보드: 총 단어 수, 총 문법 수, 연속 학습일(스트릭), 예상 레벨(N5~N1)
- 취약 항목 리스트: 오답률 높은 단어/문법 자동 표시

## 4.4 다음 학습 프롬프트 생성 (Export) — 차별화 핵심

복습 결과를 반영해 **AI에 바로 붙여넣을 수 있는 프롬프트**를 자동 생성:

```
너는 일본어 회화 선생님이야. 아래 조건으로 오늘 수업을 진행해줘.

[내 현재 수준] JLPT N5 상위 ~ N4 초반
[지난 학습] ～ばいいですか / 길 묻기 & 카페 주문
[취약 항목 - 오늘 복습 포함해줘]
- 단어: 注文(ちゅうもん), 飲み物(のみもの)   ← 정답률 40% 이하
- 문법: ～ばいいですか 활용 (특히 する→すれば)
[오늘 새로 배울 것] ～てもいいですか
[회화 주제] 🚉 전철역에서 표 사기
[수업 후] 반드시 아래 표준 노트 포맷으로 정리해줘: (템플릿 첨부)
```

→ 이 프롬프트로 학습한 결과 노트를 다시 임포트하면 루프가 이어진다.

# 6. 화면 구성

```
[홈(대시보드)]
 ├─ 오늘 복습할 카드 수 / 스트릭 / 레벨
 ├─ [복습 시작] 버튼
 └─ 최근 세션 목록
[임포트]
 ├─ 노트 붙여넣기 / 파일 업로드
 └─ 파싱 결과 미리보기 → 확인 후 저장
[복습]
 ├─ 모드 선택 (플래시카드 / 빈칸 / 회화 / 한자)
 └─ 카드 진행 → 결과 요약
[기록]
 ├─ 세션 타임라인
 ├─ 통계 (정답률, 누적 단어/문법)
 └─ 취약 항목
[프롬프트 생성]
 └─ 다음 학습 프롬프트 미리보기 → 복사 버튼
[설정]
 └─ 템플릿 관리 / 데이터 백업(JSON 내보내기)
```

# 7. 기술 스택 제안

| 영역 | 선택 | 이유 |
|------|------|------|
| 프레임워크 | React + Vite (PWA) | 웹으로 시작해 모바일 홈화면 설치 지원, 이후 앱스토어 확장 용이 |
| 저장소 | IndexedDB (localStorage 폴백) | 서버 없이 기기 내 저장 — MVP는 백엔드 불필요 |
| 파서 | 자체 마크다운 규칙 파서 | 표준 템플릿 전제, 오프라인·무료 |
| AI 파싱(선택) | Claude API (구조화 JSON 출력) | 비정형 노트 대응, Phase 2 |
| 백업 | JSON 내보내기/가져오기 → (추후) 클라우드 동기화 | 데이터 소유권은 사용자에게 |

# 8. 로드맵

## Phase 1 — MVP (핵심 루프 완성)
- [ ] 표준 템플릿 마크다운 파서
- [ ] 임포트 → 미리보기 → 저장
- [ ] 단어 플래시카드 + Leitner SRS
- [ ] 세션 기록 저장 / 대시보드(오늘 복습 수, 스트릭)
- [ ] 다음 학습 프롬프트 생성 + 복사

## Phase 2 — 학습 모드 확장
- [ ] 빈칸 채우기(문법) / 한자 퀴즈 / 자연스러움 퀴즈
- [ ] 통계 화면(정답률 추이, 취약 항목)
- [ ] Claude API 연동 — 비정형 노트 파싱

## Phase 3 — 심화
- [ ] 앱 내 AI 회화 롤플레이 (프롬프트 생성 → 앱 안에서 바로 대화)
- [ ] 클라우드 동기화 / 멀티 디바이스
- [ ] JLPT 레벨 자동 추정 고도화
- [ ] 다국어 확장 (일본어 외 언어 템플릿)

# 9. 성공 지표 (MVP 기준)

- 루프 완주율: 임포트 → 복습 → 프롬프트 생성까지 도달한 세션 비율
- 주간 복습 유지율 (스트릭)
- 세션당 임포트 소요 시간 < 30초 (파싱 정확도)
