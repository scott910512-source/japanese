# 📄 표준 학습 노트 템플릿 (앱 파싱용)

앱이 자동으로 파싱하는 표준 포맷이다.
AI에게 학습을 마칠 때 **이 템플릿 그대로 정리해 달라고 요청**하면,
결과물을 앱에 붙여넣는 것만으로 임포트가 완료된다.

파서가 인식하는 규칙:
- `#` 헤더의 이모지+제목으로 섹션을 식별한다 (제목 텍스트 기준, 이모지는 무시)
- 단어/비교 표는 마크다운 표(`|`) 형식을 유지해야 한다
- 날짜는 `YYYY-MM-DD` 형식

---

## AI에게 보낼 정리 요청 프롬프트

```
오늘 학습한 내용을 아래 템플릿 형식 그대로 마크다운으로 정리해줘.
섹션 제목과 표 형식을 바꾸지 말고, 없는 섹션은 생략해도 돼.
```

---

## 앱 → 필드 매핑 요약

| 노트 섹션 | 앱 데이터 | 생성되는 학습 자료 |
|-----------|-----------|-------------------|
| 오늘의 핵심 문법 | `grammar[]` | 문법 카드, 빈칸 퀴즈 |
| 오늘 배운 회화 | `dialogues[]` | 회화 롤플레이 |
| 오늘 배운 단어 | `words[]` | 플래시카드 (SRS) |
| 한자 공부 | `kanji[]` | 한자 퀴즈 |
| 일본인이 더 많이 쓰는 표현 | `natural_pairs[]` | 자연스러움 퀴즈 |
| 복습 문장 | `review_sentences[]` | 문장 퀴즈 |
| 학습 기록 | `session` 메타데이터 | 레벨/추천 갱신, 다음 프롬프트 생성 |
